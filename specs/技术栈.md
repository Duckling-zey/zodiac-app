# 技术栈选型

## 1. 核心决策 (Key Decisions)
选用 UniApp + Vue3 + TypeScript 实现全平台覆盖，一套代码可编译到 H5、小程序（微信/支付宝）、App（iOS/Android）。Vue3 的组合式 API 和 TypeScript 的类型系统提供更好的开发体验和代码质量。

## 2. 前端 (Frontend)
- **框架**: UniApp + Vue 3 (Composition API)
- **样式方案**: TailwindCSS + UnoCSS
- **状态管理**: Pinia
- **UI 组件库**: uni-ui (官方组件库)
- **构建工具**: Vite

## 3. 后端 (Backend)
- **运行时/语言**: Node.js / Bun
- **Web 框架**: Express / Koa
- **API 协议**: RESTful API

## 4. 数据存储 (Database)
- **主数据库**: SQLite (本地存储) / MongoDB (服务端)
- **缓存**: 本地缓存 + Storage

## 5. 基础设施 & 工具 (Infra & Tools)
- **包管理**: pnpm
- **版本控制**: Git
- **开发工具**: VS Code + Volar
