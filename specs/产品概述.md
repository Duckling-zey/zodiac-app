# 产品概述

## 1. 项目名称
星座解析

## 2. 核心价值
为星座爱好者提供专业、全面的星座分析服务，包括每日运势查询、星座匹配分析、星座性格解析和个人星盘分析。

## 3. 目标用户
星座爱好者

## 4. 核心功能板块
- **每日运势**: 提供每个星座的每日运势分析，包括综合运势、爱情运势、事业运势、财运四个维度
- **星座匹配**: 分析两个星座之间的匹配度，提供相关系数、相处建议和星座组合特点
- **星座性格分析**: 详细的星座性格特点解析，包括性格优势、潜在弱点、情感表现、职业倾向等
- **星盘分析**: 基于用户的出生日期、出生时间和出生地点，生成个人星盘并进行专业解析

## 5. 技术约束
- 使用 Vue3 + TypeScript 技术栈
- 使用 UniApp 框架实现全平台覆盖（H5、小程序、App）
- 使用 UnoCSS 进行原子化样式管理
- 使用 Pinia 进行状态管理
