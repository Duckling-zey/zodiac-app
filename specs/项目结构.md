## 2. 关键文件说明 (Key Files)
- **package.json**: 项目依赖管理文件
- **tsconfig.json**: TypeScript 配置文件
- **vite.config.ts**: Vite 构建配置
- **uno.config.ts**: UnoCSS 原子化 CSS 配置
- **src/utils/zodiac-data.ts**: 星座基础数据（12星座的基本信息、日期范围、守护星、元素等）
- **src/utils/horoscope-calc.ts**: 运势计算核心逻辑
- **src/composables/useDoubao.ts**: AI模型调用封装（智谱大模型）
- **src/styles/global.css**: 宇宙风设计系统（CSS变量定义）

## 3. 模块说明 (Module Description)
| 模块 | 路径 | 功能说明 |
|------|------|----------|
| 每日运势 | pages/index | 展示当前选中星座的每日运势，包括综合、健康、人际、学习/考试四个维度 |
| 星座匹配 | pages/match | 分析两个星座之间的匹配度，提供相关系数、相处建议，支持爱情、友情、职场、家庭等多种关系类型 |
| 性格分析 | pages/personality | 展示星座的性格优势、潜在弱点、爱情风格、职业倾向，提供互动式性格测试功能 |
| 星盘分析 | pages/horoscope | 基于出生信息生成个人星盘，展示行星分布、元素分析，提供动态星盘和行星相位分析 |
| AI问答 | pages/ai | 基于智谱大模型的智能问答对话界面，支持场景化问答 |
| 星座社区 | pages/community | 用户可以浏览和发布星座相关的帖子，支持点赞、评论和分享功能 |
| 占星学知识库 | pages/knowledge | 提供占星学相关的知识文章，按分类组织内容，支持搜索和筛选 |
| 星座日历 | pages/calendar | 展示星座相关的重要日期和事件，包含新月、满月、行星逆行等天文事件 |
| 星座测试中心 | pages/test-center | 提供多种星座相关测试（性格、爱情、职业），保存测试历史记录 |
| 个性化设置 | pages/settings | 个人资料设置、通知设置、主题设置、隐私设置 |
| 底部导航 | components/TabBar | 应用底部导航栏，切换多个功能页面 |

## 4. 文件放置规则 (Placement Rules)
- **页面文件**: 放在 `src/pages/[模块名]/index.vue`
- **组件文件**: 放在 `src/components/[类型]/[组件名].vue`
- **业务逻辑**: 放在 `src/composables/`，禁止直接写在 UI 组件中
- **类型定义**: 放在 `src/types/` 目录
- **全局样式**: 放在 `src/styles/global.css`
- **环境变量**: 在 `.env` 文件中配置，类型定义在 `env.d.ts`

## 5. 技术栈清单
- **框架**: Vue 3.4+ (Composition API)
- **语言**: TypeScript 5.0+
- **构建**: Vite 5.0+
- **路由**: Vue Router 4.0+
- **状态**: Pinia 2.0+
- **样式**: UnoCSS + CSS Variables
- **Markdown**: marked 12.0+
- **AI模型**: 智谱大模型 glm-4-flash
