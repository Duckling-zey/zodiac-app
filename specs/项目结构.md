# 项目结构

## 1. 目录树 (Directory Tree)
```
/
├── specs/                      # 项目核心定义 (产品/技术/结构/规范)
├── docs/                       # 项目文档
├── src/                        # 源代码
│   ├── pages/                  # 页面 (UniApp 页面目录)
│   │   ├── index/              # 首页 - 每日运势
│   │   ├── match/              # 星座匹配
│   │   ├── personality/        # 性格分析
│   │   └── horoscope/          # 星盘分析
│   ├── components/             # 通用组件
│   │   ├── common/             # 基础组件
│   │   └── zodiac/             # 星座专属组件
│   ├── composables/            # 组合式函数 (Vue3 Composition API)
│   │   ├── useZodiac.ts        # 星座数据相关
│   │   └── useHoroscope.ts     # 运势计算相关
│   ├── stores/                 # Pinia 状态管理
│   │   └── zodiac.ts           # 星座数据状态
│   ├── services/               # API 服务层
│   │   └── api.ts              # API 请求封装
│   ├── utils/                  # 工具函数
│   │   ├── zodiac-data.ts      # 星座基础数据
│   │   └── horoscope-calc.ts   # 运势计算逻辑
│   ├── types/                  # TypeScript 类型定义
│   │   └── zodiac.ts           # 星座类型定义
│   ├── static/                 # 静态资源
│   └── App.vue                 # 应用入口
├── index.html                  # H5 入口
├── package.json
├── tsconfig.json
├── vite.config.ts
├── uno.config.ts               # UnoCSS 配置
└── README.md
```

## 2. 关键文件说明 (Key Files)
- **package.json**: 项目依赖管理文件
- **tsconfig.json**: TypeScript 配置文件
- **vite.config.ts**: Vite 构建配置
- **uno.config.ts**: UnoCSS 原子化 CSS 配置
- **src/utils/zodiac-data.ts**: 星座基础数据（12星座的基本信息、日期范围、守护星等）
- **src/utils/horoscope-calc.ts**: 运势计算核心逻辑

## 3. 模块说明 (Module Description)
- **pages/index**: 首页模块 - 展示每日运势
- **pages/match**: 星座匹配模块 - 两个星座的匹配度分析
- **pages/personality**: 性格分析模块 - 单个星座的详细性格解析
- **pages/horoscope**: 星盘分析模块 - 基于出生信息的个人星盘
- **composables/**: 组合式函数 - 可复用的业务逻辑
- **stores/**: 全局状态管理
- **services/**: API 服务层 - 与后端交互

## 4. 文件放置规则 (Placement Rules)
- **页面文件**: 放在 `src/pages/[模块名]/index.vue`
- **组件文件**: 放在 `src/components/[类型]/[组件名].vue`
- **业务逻辑**: 放在 `src/composables/`，禁止直接写在 UI 组件中
- **类型定义**: 放在 `src/types/` 目录
