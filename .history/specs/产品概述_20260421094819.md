# 产品概述

## 1. 项目名称
星座解析

## 2. 核心价值
为星座爱好者提供专业、全面的星座分析服务，包括每日运势查询、星座匹配分析、星座性格解析、个人星盘分析、AI智能问答、星座社区、占星学知识库、星座日历、星座测试中心和个性化设置功能。

## 3. 目标用户
- 星座爱好者
- 对个人运势感兴趣的人群
- 希望了解自己和他人性格的用户
- 对占星学有兴趣的用户
- 寻求社区互动和知识分享的用户

## 4. 核心功能板块
- **每日运势**: 提供每个星座的每日运势分析，包括综合运势、健康运势、人际运势、学习/考试运势四个维度
- **星座匹配**: 分析两个星座之间的匹配度，提供相关系数、相处建议和星座组合特点，支持爱情、友情、职场、家庭等多种关系类型
- **星座性格分析**: 详细的星座性格特点解析，包括性格优势、潜在弱点、情感表现、职业倾向等，提供互动式性格测试功能
- **星盘分析**: 基于用户的出生日期、出生时间和出生地点，生成个人星盘并进行专业解析，提供动态星盘和行星相位分析
- **AI智能问答**: 基于智谱大模型，提供个性化的星座相关问题解答服务，支持场景化问答（爱情、事业、生活、性格）
- **星座社区**: 用户可以浏览和发布星座相关的帖子，支持点赞、评论和分享功能
- **占星学知识库**: 提供占星学相关的知识文章，按分类组织内容，支持搜索和筛选
- **星座日历**: 展示星座相关的重要日期和事件，包含新月、满月、行星逆行等天文事件
- **星座测试中心**: 提供多种星座相关测试（性格、爱情、职业），保存测试历史记录
- **个性化设置**: 个人资料设置、通知设置、主题设置、隐私设置

## 5. 用户交互流程
- 用户首次进入应用时，可以选择或切换不同的星座
- 底部导航栏提供多个功能的快速切换
- 星座选择采用点击弹出选择器的交互方式
- 各功能页面头部固定，内容区域可滚动
- AI问答页面输入框固定在底部，对话内容可滚动

## 6. 技术约束
- 使用 Vue3 + TypeScript 技术栈
- 使用 Vite 作为构建工具
- 使用 Pinia 进行状态管理
- 使用 Vue Router 进行路由管理
- 使用原生 CSS（CSS变量）进行样式管理
- 使用 marked 库解析 Markdown 文档格式
- AI对话功能接入智谱大模型（glm-4-flash）

## 7. 设计风格
- **主题**: 神秘的宇宙风
- **配色**: 深空黑紫色系背景，渐变紫色强调色
- **动效**: 卡片悬停发光效果、页面切换动画、动态星盘展示
- **布局**: 响应式设计，适配移动端和桌面端
