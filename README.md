# 星座解析

为星座爱好者提供专业、全面的星座分析服务。

## 技术栈

- UniApp + Vue 3
- TypeScript
- UnoCSS
- Pinia

## 功能模块

- 每日运势
- 星座匹配
- 星座性格分析
- 星盘分析

## 开发

```bash
# 安装依赖
pnpm install

# 开发调试
pnpm dev

# 构建
pnpm build
```

## 项目结构

```
src/
├── pages/          # 页面
├── components/     # 组件
├── composables/    # 组合式函数
├── stores/         # 状态管理
├── services/       # API 服务
├── utils/          # 工具函数
└── types/          # 类型定义
```
